# XioiX

Canal oficial de descargas de XioiX para Fire TV.

## Descargas y versiones

Los APK y las notas de cada versión se publican en [Releases](https://github.com/Errorx0x/XioiX/releases).

**Primera versión pública en preparación. Todavía no hay un APK publicado.**

## Qué contiene este repositorio

Este repositorio se utiliza para distribuir la app y sus actualizaciones. El código propio de XioiX se mantiene privado.

Cada entrega incluirá los avisos y materiales correspondientes a sus componentes de terceros.
