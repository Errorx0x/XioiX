# XioiX

Canal oficial de descargas de XioiX para Fire TV.

## Descargar

[**Descargar el último APK**](https://github.com/Errorx0x/XioiX/releases/latest/download/XioiX.apk) · [Versiones y novedades](https://github.com/Errorx0x/XioiX/releases)

Android 6 o posterior. Incluye ARM de 32 y 64 bits; probado en Fire TV AFTSS con Android 9.

## Actualizar

Desde XioiX 0.6.6: abre **Ajustes → Actualizar XioiX → Buscar actualización**. Cuando haya una versión nueva, podrás descargarla e iniciar su instalación. Fire TV puede pedir autorizar a XioiX para instalar aplicaciones.

Para la primera instalación o si vienes de una versión anterior, descarga el APK. Actualiza sobre la instalación existente para conservar perfiles, favoritos y progreso.

La app comprueba la identidad, versión, firma y SHA-256 del APK antes de abrir el instalador del sistema. Las versiones incluyen `update.json` y `SHA256SUMS.txt`.

## Contenido del repositorio

Aquí se publican APK, notas de versión y materiales de terceros. El código propio de XioiX y las configuraciones personales de fuentes permanecen privados.

Las fuentes y licencias de FFmpeg/Media3 y TorrServer se adjuntan a cada versión. Los enlaces automáticos de GitHub llamados «Source code» contienen únicamente los archivos de este repositorio de distribución.
